# Ханна / ТЕТРАГРАМАТОН

Готовый сайт: https://rarivari9-commits.github.io/-/hanna/

Код размещён отдельной папкой `hanna` в репозитории `rarivari9-commits/-`. Для вставки в Тильду используйте `tilda-embed.html`: адрес уже заполнен.

Интерактивная анкета: фигура в полный рост → волна сканирования → голова → правый локоть → левое колено. Стиль взят из предоставленного кода системы: фон #090705, янтарный #ffa20a, пиксельная сетка 2px, Courier New и Georgia, CRT-полосы. Объёмная фигура — стилизованный процедурный прототип по рисункам и артам, а не готовая детальная модель персонажа.

## Просмотр

Откройте `hanna.html` или `index.html` в современном браузере. Оба файла автономны: дополнительных изображений, CDN и сборки не требуется. `hanna.html` — копия для удобного просмотра; для GitHub Pages достаточно `index.html`.

Нажмите на фигуру или «Открыть досье». Стрелка справа переключает точки. Стрелка на последнем разделе возвращает к фигуре. Кнопки 01 / 02 / 03 позволяют перейти напрямую. «Общий вид» и Escape возвращают к полному росту; ← и → переключают разделы. На телефоне — те же касания и кнопки. При включённом системном сокращении движения переходы происходят сразу.

## GitHub Pages

1. Создайте отдельный репозиторий `hanna-dossier`. Для бесплатного GitHub Pages можно использовать публичный репозиторий.
2. Загрузите в его корень `index.html`, `.nojekyll` и `LICENSE-three.txt` из этого архива. Лицензию библиотеки сохраните. Остальные файлы в архиве — инструкция и код для Тильды.
3. В Settings → Pages → Build and deployment выберите Deploy from a branch, затем `main` и `/(root)` → Save.
4. Дождитесь публикации. Точный адрес будет показан в Settings → Pages. Обычно это `https://ВАШ-ЛОГИН.github.io/hanna-dossier/`.
5. Откройте этот адрес отдельно и проверьте переходы перед вставкой в Тильду.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Тильда

Добавьте блок T123 «HTML-код». Скопируйте содержимое `tilda-embed.html` — адрес опубликованной анкеты уже заполнен. Затем опубликуйте страницу Тильды: HTML-блок следует проверять на опубликованной странице.

Обнулите верхний и нижний отступы блока T123 и используйте ширину на весь экран, если такие параметры доступны в вашем шаблоне. Если используется собственная шапка Тильды, можно подстроить высоту `.hanna-embed` в коде вставки. Досье адаптируется к размеру iframe.

Официальная инструкция: https://help.tilda.cc/html

## Заполнение анкеты

Откройте `index.html` в редакторе. Найдите `window.HANNA_PROFILE` (ближе к началу файла, перед большим кодом 3D). Все три поля `body` оставлены пустыми по заданию. Впишите текст внутрь кавычек, например:

```js
{ title: "Кто она", body: "Здесь будет история Ханны.\nНовая строка." }
```

Используйте `\n` для переноса строки и `\"` для кавычек внутри текста. Вставляйте обычный текст; HTML в анкете не выполняется. После изменения загрузите обновлённый `index.html` в тот же репозиторий — адрес и код Тильды сохранятся.

## Исходный проект

В автономном `index.html` находятся все стили, данные и код фигуры. Код не минифицирован; в конце файла можно найти `createHanna` (модель), `viewFor` (ракурсы) и `goTo` (переключение). Никаких внешних файлов для работы страницы не требуется.

Проекция камеры и отсутствие обрезки общего вида проверены программно на восьми размерах экрана. Вид головы дополнительно проверен расчётом на телефонах и планшете. Выполнен программный рендер фигуры; полноценная проверка в браузере в среде сборки недоступна.
